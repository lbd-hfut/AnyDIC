# ANYDIC 后续科研路线

> 公开发布副本：本机路径已符号化，操作台账按隐私范围精简；科学结论沿用冻结源文档。修改及历史验证范围见 [PUBLICATION_NOTICE](PUBLICATION_NOTICE.md)。

生产 LOW 保持 AnyDIC V2.0 Final。研究目标是任意有效 Query 的真实对应恢复，同时减少大位移/复杂非均匀场成片失败并保留原正确点；物理位移/梯度与跨尺度一致性须独立验证。

| 路线 | 当前定位 | 下一步 |
| --- | --- | --- |
| Route 1：冻结 D4 | 历史基准与可复现对照；C2 有界合成资格 | 保留原算法、模型和失败人口；不自动升级为下一代默认 matcher |
| Route 2：C11 SEA-RAFT M | 独立合成 GT 支持的主要新匹配候选 | 先复核 GPU 原轨迹和原正确保护，再研究更新稳定性与新独立协议 |
| Route 3：GMFlow + RAFT | 尚未实现/取得资格的未来方案 | 按联合架构设计研究共享特征、长距离粗初始化与 Query 级连续 refinement |

近期优先级是 Route 2 的诊断：复核 C15 原 GPU 中间轨迹，区分 latent flow、hidden state、相关查找与 convex upsampling 的作用；用 Decoder-only 控制和 Joint-state 干预检验正确点保护与恢复的联合机会。C16-B 尚未正式启动，文档中的设计不是授权运行或验证成功。

之后才决定多尺度训练与 Route 3 投入。必须解决跨尺度物理一致性、原正确点保护、Sinusoidal/Star-like 周期场、R3 更新稳定性、高分辨率训练/推理、更广纹理及 PSF/光照/噪声泛化。C13/C14/C15 的负 Gate 与 C16 数值重建限制永久保留；旧暴露人口只能做历史诊断/对照，下一阶段必须从冻结证据和新独立协议出发。

开发组织改为主项目读取本目录，源码留在历史分支，原数据从外部归档按 manifest 定位。按任务创建短期 checkout 或新研究分支即可，无需永久并存重复 worktree。不得直接合并历史实验代码到生产 LOW。
