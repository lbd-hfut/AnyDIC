# GMFlow + RAFT 联合架构研究方案

> 公开发布副本：本机路径已符号化，操作台账按隐私范围精简；科学结论沿用冻结源文档。修改及历史验证范围见 [PUBLICATION_NOTICE](PUBLICATION_NOTICE.md)。

**未来研究方案，尚未实现或取得科学资格。现有 C11/C16 没有完成 GMFlow+SEA-RAFT 联合求解器。** C11 是官方 SEA-RAFT M 全网络加连续 Query readout；C13 的尺度归一/原生流注入是 SEA 自身诊断，不能称作 GMFlow 联合架构。

目标是 GMFlow 提供长距离粗对应，SEA-RAFT 迭代修复局部对应；以共同参考/目标坐标、有效支持、像素 spacing 和物理尺度协议共享合法图像特征及运动信息。当前两者编码器/通道/步幅/训练分布不同，共享须通过显式适配及新的独立验证，不能假定互换。

先比较独立双编码器对照与共享 encoder/adapter 方案，量化昂贵编码、相关体、内存和时间成本。粗流接口必须绑定参考坐标、padding、方向、单位、tensor stride、validity 和不可观测 target；粗流只初始化对应，不能借 GT 选择模型。

任意不规则 Query 接口保持顺序/子集/重复/批处理一致性。稠密 flow 插值可以作为对照，核心新问题是 Query 级连续局部相关与 refinement：在浮点 Query 处合法采样参考/目标特征、保留多个粗候选，并以真实目标图像证据生成连续位置。该功能尚未验证，也不能把最终平滑包装为对应恢复。

保护已经正确的 GMFlow 初始化是独立主要门槛。记录 coarse→每次更新的 correct→wrong、wrong→correct、严重错误连通面积、native半像素/物理阈值及不同族/尺度分层。研究 Decoder-only 控制、兼容的 flow/hidden/convex 权重联合状态更新；不会假设 C16 单点输出阈值可直接推广。

阶段门槛：

1. 冻结 D4/C11/C13/C15 源码/权重/轨迹身份，原 GPU 轨迹先复核；以不同输出目录保存新结果。
2. 注册新的独立 TRAIN/DEV/LOCKED 物理 worlds、尺度、位移/梯度/周期/纹理与成像因子，冻结 Query/有效性/资源门槛和停止规则。
3. 用无 GT 推理的粗初始化接口及 Decoder-only/联合状态有界干预检验机制；先证明保护和实际对应恢复，再决定训练。控制比较同编码预算、初始化与迭代次数，GT oracle 仅离线诊断。
4. 再评价共享特征和 Query 连续求解，隔离收益来源；完整原生高分辨率推理/训练与大位移复杂非均匀场独立验收。
5. 新锁定集一次性确认和真实独立2D GT/物理计量验证通过之前，不进入 LOW 生产，也不授予下一代默认资格。

本任务仅提供方案及证据约束，不启动架构实现或 C16-B。
